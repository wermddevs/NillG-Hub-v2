# NillG Hub v2

# 📄 NILLG HUB - DESCRIÇÃO E TERMOS DE USO

# 🔥 SOBRE O SCRIPT
O NillG Hub é focado em farm automático de kills para contas alternativas (alt accounts) no The Strongest Battlegrounds.

# ⚙️ FUNCIONALIDADES

AutoReset: Reseta ao aproximar de 0 de vida

Noclip / Teleport / Set Spawn: Movimentação e arena

Anti Lag & FPS Cap: Otimização de desempenho

Rejoin & Kill Counter: Reconexão e contador em tempo real

# 🔐 SISTEMA DE SEGURANÇA
Requer chave de acesso (Key System) via tela de autenticação ao executar.

# 📋 TERMOS DE USO

Aceitação: O uso do script implica concordância total com estes termos.

Responsabilidade: Fornecido "como está". Use apenas em contas alternativas (alts). O usuário assume o risco de punições ou banimentos.

Proibições: Proibido revender, modificar, burlar a chave, compartilhar acessos ou usar em conta principal.

Isenção: Os desenvolvedores não se responsabilizam por banimentos, perda de contas ou interrupções de serviço.

Atualizações: Podem ocorrer alterações em funções ou bloqueios sem aviso prévio.

# 🎯 COMO USAR

Obtenha a chave via Discord.

Execute o script no executor de sua preferência.

Insira a chave na tela de autenticação e clique em "SUBMIT".

Ative as funções desejadas no painel.
